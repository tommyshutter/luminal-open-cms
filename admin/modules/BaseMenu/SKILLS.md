# BaseMenu — Skills Reference

## Overview
Base site admin menu provider. Defines the menu sections (content, ecommerce, events, system admin) for all base-tier sites. This module is a menu source of truth — it contains no UI of its own.

## Capabilities
- Provides menu section definitions for base-tier admin panel
- Defines content, ecommerce, events, and system admin menu groups
- Auto-discovered by module_loader.php

## Data Storage
- Module directory contains menu definition files only

## Dependencies
- None (foundational menu provider)

## Common Tasks
1. **Modify menu sections**: Edit menu definition files in the module directory to add/reorder sections
