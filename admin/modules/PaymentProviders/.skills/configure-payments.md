# Skill: Configure Payment Gateways

## Overview
Set up payment processing with PayPal, Stripe, or Square.

## Prerequisites
- Admin access
- Payment provider account with API credentials

## Procedure
1. Navigate to Admin > Payment Methods
2. Select gateway (PayPal, Stripe, or Square)
3. Enter API credentials (keys, secrets)
4. Enable the gateway
5. Set as default if primary
6. Test connection to verify
7. Set currency

## Verification
- Test connection returns success
- Gateway shows as enabled
- Checkout flow processes test payment
