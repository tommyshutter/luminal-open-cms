# Skill: Manage Affiliate Products

## Overview
Add, edit, reorder, and delete affiliate products from multiple retailers.

## Prerequisites
- Admin access
- Retailer API credentials configured (optional, for AI discovery)

## Procedure
1. Navigate to Admin > Affiliates
2. To add manually: Click Add Product, fill in title, URL, image, price, retailer
3. To use AI discovery: Click Discover, enter search terms, review suggestions, approve
4. To reorder: Drag products to desired order, changes auto-save
5. To delete: Click delete icon on product card, confirm

## Verification
- Product appears in the product list
- Product renders on the public storefront page
