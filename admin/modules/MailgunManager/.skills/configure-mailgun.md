# Skill: Configure Mailgun

## Overview
Set up Mailgun email service for transactional email delivery.

## Prerequisites
- Admin access
- Mailgun account with API key
- Domain configured in Mailgun dashboard

## Procedure
1. Navigate to Admin > Mailgun
2. Enter Mailgun API key
3. Enter sending domain
4. Set from name and email address
5. Save configuration
6. Click Test to verify API connectivity
7. Send a test email to confirm delivery
8. Check DNS to verify domain records

## Verification
- Test returns success
- Test email arrives in inbox
- DNS check shows all records verified
