# Skill: Manage Site Text Slots

## Overview
Create and manage dynamic content slots that render via shortcodes on site pages.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Site Text
2. View existing content slots
3. Create new slot by pushing content to a key
4. Edit existing slot content
5. Embed on pages using `[[site-text:key]]`
6. View history and revert if needed

## Verification
- Content slot appears in list
- `[[site-text:key]]` renders content on page
- History tracks all changes
- Revert restores previous content
