# Skill: Manage YouTube Playlists

## Overview
Create, configure, and embed YouTube playlists on site pages.

## Prerequisites
- Admin access
- YouTube Data API key
- YouTube playlist ID

## Procedure
1. Navigate to Admin > YT Playlist Studio
2. Click "New Playlist"
3. Enter YouTube playlist ID
4. Enter YouTube Data API key for this playlist
5. Save and preview
6. Copy shortcode for page embedding
7. Clear cache when playlist updates

## Verification
- Preview shows correct videos from playlist
- Shortcode renders playlist on page
- Cache clear fetches updated playlist data
