# Skill: Manage Media Thumbnails

## Overview
Generate, diagnose, and maintain thumbnail cache for site media.

## Prerequisites
- Admin access
- Media files in /media directory

## Procedure
1. Navigate to Admin > Media Thumbs
2. Select folders to scan (checkboxes)
3. Click Generate to create thumbnails
4. Use Diagnostics tab to find missing thumbnails
5. Monitor cache size per folder

## Verification
- Thumbnails appear in .cache directories
- Diagnostics shows no missing thumbnails
- Gallery and media browser display thumbnails correctly
