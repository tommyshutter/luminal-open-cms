# Skill: Publish a Social Media Post

## Overview
Compose and publish posts to Facebook Pages or Twitter/X with optional AI assistance.

## Prerequisites
- Admin access
- Social media provider configured (Facebook or Twitter)
- AIResources configured (for AI generation features)

## Procedure
1. Navigate to Admin > Social Publisher
2. Click "New Post"
3. Write content or use AI to generate
4. Attach image (upload or AI-generate)
5. Select target provider(s)
6. Preview post
7. Publish

## Verification
- Post appears on target social media platform
- Post appears in post history
- Image displays correctly on platform
