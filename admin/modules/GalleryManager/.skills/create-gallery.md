# Skill: Create a Gallery

## Overview
Build image, video, PDF, or combined galleries with layout controls and shortcode embedding.

## Prerequisites
- Admin access
- Media files uploaded to site

## Procedure
1. Navigate to Admin > Gallery Mgr
2. Select gallery type tab (Images, Videos, PDFs, Combined)
3. Click "New Gallery"
4. Enter gallery name
5. Drag media from browser into gallery
6. Set layout (grid/masonry/rows) and column count
7. Reorder items as needed
8. Save gallery
9. Copy shortcode for page embedding

## Verification
- Gallery appears in gallery list
- Preview iframe shows correct layout
- Shortcode renders gallery on target page
