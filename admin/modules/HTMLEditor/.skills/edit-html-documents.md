# Skill: Edit HTML Documents

## Overview
Create and edit rich HTML documents using the WYSIWYG editor.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > HTML Editor
2. Create new or load existing document
3. Use formatting toolbar for text styling
4. Insert media via media browser
5. Toggle source view for raw HTML editing
6. Use Find & Replace for bulk text changes
7. Save document (Ctrl+S shortcut available)

## Verification
- Document saves without error
- Document appears in document list
- Content renders correctly in preview
