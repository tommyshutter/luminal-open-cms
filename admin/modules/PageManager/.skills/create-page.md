# Skill: Create and Edit Pages

## Overview
Create, edit, and manage site pages using the card-based page manager.

## Prerequisites
- Admin or staff access

## Procedure
1. Navigate to Admin > Page Mgr
2. Click "New Page" for new, or click existing page card to edit
3. Enter page slug (URL path)
4. Add content using the WYSIWYG editor
5. Configure two-column layout if needed
6. Add shortcodes for galleries, panels, or dynamic content
7. Set meta title and description for SEO
8. Preview in iframe before saving
9. Save page

## Verification
- Page accessible at configured URL
- Content renders correctly on frontend
- Shortcodes resolve to embedded content
- Per-page CSS applies to page only
