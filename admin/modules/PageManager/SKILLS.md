# PageManager — Skills Reference

_Last refresh: 2026-04-23_

## Overview
The CMS's primary page CRUD module. Card grid browser + modal editor with iframe preview + revision history + per-page CSS. All user-facing pages flow through PageManager — no standalone PHP apps at site root.

## Capabilities
- Card-based page browser with preview thumbs
- Modal editor with CKEditor-like toolbar + CPM Blocks sidebar
- Live iframe preview (`/page.php?p={slug}`)
- Two-column layout engine (left_width / right_width, must sum to 100)
- Component-based content (`main_content`, `right_column`)
- Revision history — up to 5 kept as `{slug}.YYYYMMDD-HHMMSS.rev.json`, auto-pruned via `ri_rev_prune_to_5`
- **Versions picker** (2026-04-22) — toolbar button opens modal listing revisions, user picks one to load into editor, reviews, clicks Save to promote
- **Pretty HTML** / **Minify HTML** toolbar buttons (2026-04-21) — reflow or compress the current column's HTML
- Per-page CSS — `admin/data/pages/{slug}/{slug}.css` injected as `<style id="page-css">` (highest cascade priority)
- Per-page JS support (inlined `<script>` in content or linked file)
- Shortcode support — galleries, stacks, panels, podcasts, events, affiliate products, forms
- AI Assist — generates HTML fragments via `AIResources/api.php?action=generate_fragment`
- AIP (AI Page) import — read-only pages generated by AI pipelines
- Meta title + description for SEO
- Delete → moves page directory to `admin/data/pages_trash/` (recoverable)

## API Endpoints
- `action=load` — Load page JSON
- `action=save` — Save page (writes revision first, then `{slug}.json`)
- `action=delete` — Move to trash
- `action=list_aip_pages` — List AIP imports
- `action=delete_aip_page` — Remove an AIP page
- `?__revs=1&slug=X` — List revisions for slug (used by Versions picker)
- `?__rev_get=1&slug=X&rev=Y` — Fetch a specific revision
- POST `?__rev_delete=1` — Delete a specific revision

## Data Storage
- `admin/data/pages/{slug}/{slug}.json` — current page
- `admin/data/pages/{slug}/{slug}.css` — per-page CSS (optional)
- `admin/data/pages/{slug}/{slug}.YYYYMMDD-HHMMSS.rev.json` — revisions (max 5)
- `admin/data/pages_trash/{slug}/` — soft-deleted pages

## Dependencies
- None (core module)
- AIResources is OPTIONAL — AI Assist won't appear if AI is not configured

## Common Tasks
1. **Create a page**: + New Page → enter title → editor opens. Saved as `admin/data/pages/{slug}/{slug}.json`.
2. **Edit existing page**: Click card → modal opens with content loaded.
3. **Restore a revision**: Click **Versions** in toolbar → pick one → it loads into the editor → review via Preview → Save to promote.
4. **Per-page CSS**: Click **Page CSS** purple button in toolbar → edit → save. Deleted when content is cleared.
5. **Use shortcodes**: Use CPM Blocks sidebar pills or type manually — `[[stack:slug]]`, `[[image-gallery:slug]]`, `[[podcast-feed]]`, `[[affiliate-products]]`, etc.
6. **Clean up HTML**: **Pretty HTML** reflows indentation; **Minify HTML** strips whitespace.
7. **AI Assist**: Purple **AI Assist** button → prompt + tone + content type → Generate → Insert.

## Gotchas
- Pages are **fragments** — no `<html>`, `<head>`, `<body>` tags in content. `page.php` provides the shell.
- Per-page CSS is injected as `<style id="page-css">` — it overrides everything, use specificity mindfully.
- The revisions file format is `{slug}.YYYYMMDD-HHMMSS.rev.json` — the timestamp string parses to local date in Versions picker.
- Deleted pages land in `pages_trash/` — can be restored by moving the directory back.
- `saved_at` must be updated on every write (use `date('c')`).
- Pages MUST be owned by `www-data:www-data` with `0664` permissions.
