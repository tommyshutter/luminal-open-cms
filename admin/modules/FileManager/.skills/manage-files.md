# Skill: Manage Site Files

## Overview
Browse, upload, edit, and organize files using the web-based file manager.

## Prerequisites
- Staff or admin access

## Procedure
1. Navigate to Admin > File Manager
2. Use dual-pane browser to navigate directories
3. Upload: drag files to upload zone
4. Edit: click file to open editor
5. Organize: use copy/move/rename/delete operations
6. Backup: select files and create backup archive

## Verification
- Uploaded files appear in directory listing
- Edited files reflect changes
- Backups appear in backup list
