# Skill: Configure Site Settings

## Overview
Set up site identity, typography, logo, footer, and SEO configuration.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Site Settings
2. Set site name, tagline, and description
3. Upload logo image
4. Configure typography (font family, heading/body sizes)
5. Set landing page
6. Configure footer content
7. Generate OG image for social sharing
8. Run SEO scan and apply recommendations

## Verification
- Site name displays in browser title and header
- Logo renders in header area
- Footer content appears on all pages
- SEO meta tags present in page source
