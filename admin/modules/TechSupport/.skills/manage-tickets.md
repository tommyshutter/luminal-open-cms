# Skill: Manage Support Tickets

## Overview
Submit, triage, and resolve support tickets with agent-assisted workflows.

## Prerequisites
- Admin access (for management), any user (for submission)

## Procedure
1. Submit: Use support widget to describe issue
2. Triage: Review ticket dashboard, check auto-assigned agents
3. Update: Change status, add notes, request info
4. Resolve: Mark ticket as resolved with resolution notes
5. Archive: Bulk archive resolved tickets
6. Search: Use search or similar tickets to find related issues

## Verification
- Submitted tickets appear in inbox
- Status updates reflect in ticket timeline
- Resolved tickets move to appropriate state
- Archive clears resolved tickets from active view
