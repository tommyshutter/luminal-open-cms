# Skill: Configure CTA Lead Forms

## Overview
Create and customize lead capture forms that display on site pages via shortcodes.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Audience Leads
2. Click Forms tab
3. Click "New Form" or edit existing
4. Configure fields (name, email, phone, custom fields)
5. Set form styling and submit button text
6. Save form
7. Embed on pages using the generated shortcode

## Verification
- Form renders on target page
- Test submission creates a lead entry
- Lead appears in leads list
- If hub mode configured, lead forwards to AudienceCollector
