# Skill: Manage Print-on-Demand Merchandise

## Overview
Configure Printful integration and manage merchandise products.

## Prerequisites
- Admin access
- Printful account with API key

## Procedure
1. Navigate to Admin > Printful
2. Enter Printful API key
3. Sync product catalog
4. Configure products for storefront display
5. Orders flow through Printful for fulfillment

## Verification
- API connection successful
- Products sync from Printful catalog
- Orders route to Printful for printing and shipping
