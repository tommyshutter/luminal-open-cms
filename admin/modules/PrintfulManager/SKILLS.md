# PrintfulManager — Skills Reference

## Overview
Printful print-on-demand integration for merchandise management. Connects to Printful's API for creating and managing custom merchandise products.

## Capabilities
- Printful API integration
- Product catalog management
- Print-on-demand merchandise creation
- Order synchronization

## API Endpoints
- Printful API integration via module PHP

## Data Storage
- `admin/data/PrintfulManager/data/` — Product and configuration data

## Dependencies
- None

## Common Tasks
1. **Configure Printful**: Enter API key from Printful dashboard
2. **Sync products**: Import product catalog from Printful
3. **Manage merchandise**: Create and edit print-on-demand products
