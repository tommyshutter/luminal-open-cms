# Skill: Create and Manage Events

## Overview
Create, edit, and promote events with the full-featured events management system.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Events Mgr
2. Click "New Event"
3. Enter event details: title, date, time, description
4. Select or create a venue
5. Upload event image/flyer
6. Set status to Published
7. Optionally push to social media

## Verification
- Event appears in calendar view on correct date
- Event displays on public events page
- Social media post (if pushed) appears on target platform
