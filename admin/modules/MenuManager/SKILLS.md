# MenuManager — Skills Reference

## Overview
Navigation menu editor for creating, reordering, and styling site menus. Manages the public-facing navigation menus displayed on the site frontend.

## Capabilities
- Create and edit navigation menus
- Drag-and-drop menu item reordering
- Menu item styling options
- Link to pages, URLs, or anchors
- Menu hierarchy (parent/child items)

## API Endpoints
- Handler at `handler.php` for menu operations

## Data Storage
- Menu configuration files in site data directory

## Dependencies
- None

## Common Tasks
1. **Add menu item**: Click Add, enter label and link target, save
2. **Reorder items**: Drag items to new positions
3. **Create submenu**: Drag item under parent to create hierarchy
4. **Style menu**: Configure colors and hover effects
