# Skill: Edit Site Navigation

## Overview
Create and manage the site's public navigation menu.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Menu Mgr
2. Add new menu items with labels and link targets
3. Drag to reorder or create hierarchy
4. Configure styling options
5. Save menu

## Verification
- Menu changes reflect on site frontend
- Links navigate to correct pages
- Submenu items display on hover/click
