# MyStore — Skills Reference

## Overview
E-commerce store management module for products, orders, and storefront display. Provides a complete online store solution within the CMS.

## Capabilities
- Product management (create, edit, delete)
- Order tracking and management
- Storefront display configuration
- Product categories and organization
- Price and inventory management
- Product image management

## API Endpoints
- Store management via admin interface (MyStoreAdmin.php)

## Data Storage
- Product and order data in site data directories

## Dependencies
- PaymentProviders (for payment processing)

## Common Tasks
1. **Add a product**: Create product with title, description, price, images
2. **Manage orders**: View and process incoming orders
3. **Configure storefront**: Set display layout and category organization
4. **Update inventory**: Adjust stock levels for products
