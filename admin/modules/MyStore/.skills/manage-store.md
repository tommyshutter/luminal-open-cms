# Skill: Manage Online Store

## Overview
Create products, process orders, and configure the storefront.

## Prerequisites
- Admin access
- PaymentProviders configured (for checkout)

## Procedure
1. Navigate to Admin > My Store
2. Add products with title, description, price, images
3. Organize into categories
4. Configure storefront display settings
5. Monitor and process incoming orders

## Verification
- Products display on storefront page
- Add-to-cart and checkout flow works
- Orders appear in order management
