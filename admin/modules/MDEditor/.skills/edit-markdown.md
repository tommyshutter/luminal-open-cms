# Skill: Edit Markdown Documents

## Overview
Create and edit markdown documents with live preview.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > MD Editor
2. Create new or load existing document
3. Type markdown in left pane, preview renders in right pane
4. Save with Ctrl+S or Save button
5. Export as .md or .html as needed

## Verification
- Document saves and appears in document list
- Live preview renders markdown correctly
- Export produces valid output file
