# Skill: Analyze Site Logs

## Overview
Use the log viewer to investigate traffic patterns, errors, and security threats.

## Prerequisites
- Admin access
- Apache access/error logs present

## Procedure
1. Navigate to Admin > Log Viewer
2. Dashboard tab: review threat cards and top offenders
3. Access Log tab: browse requests, filter by IP or status
4. Error Log tab: filter by severity level
5. Adjust time range for broader or narrower analysis

## Verification
- Dashboard loads with current data
- Access log entries match expected traffic
- Error log captures PHP/Apache errors
