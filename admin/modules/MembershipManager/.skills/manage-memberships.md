# Skill: Manage Memberships

## Overview
Administer invite-only membership system with codes, referrals, and engagement tracking.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Membership Manager
2. Configure membership tiers in settings
3. Generate invitation codes (batch or individual)
4. Share codes with prospective members
5. Monitor member registrations and activity
6. Review leaderboard for engagement metrics
7. Track referral chains for attribution

## Verification
- Generated codes are valid and redeemable
- New members appear in member list after registration
- Activity log captures member actions
- Leaderboard reflects accurate rankings
