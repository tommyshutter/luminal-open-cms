# Skill: Manage User Accounts

## Overview
Create, edit, and manage admin user accounts with role-based access control.

## Prerequisites
- Admin access (for staff), superadmin (for admin/permission management)

## Procedure
1. Navigate to Admin > Users
2. Click "Create User" for new account
3. Enter email, name, and assign role
4. Set initial password
5. Save user
6. To modify: click user, update fields, save
7. To deactivate: toggle status to inactive
8. To configure permissions: superadmin > Permission Matrix

## Verification
- New user can log in with credentials
- Role restrictions apply correctly
- Inactive users cannot log in
- Permission matrix reflects intended access
