# Dashboard — Skills Reference

## Overview
Admin dashboard providing an overview panel with quick actions and summary information. The landing page after admin login.

## Capabilities
- Overview of site status
- Quick action links to common tasks
- Summary cards for content, events, and system status

## Data Storage
- No dedicated data storage (reads from other modules)

## Dependencies
- None

## Common Tasks
1. **Access dashboard**: Log in to admin panel — dashboard loads by default
2. **Quick actions**: Use dashboard links to jump to common management tasks
