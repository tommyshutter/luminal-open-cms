# Skill: Configure Site Background

## Overview
Set and customize the site background with images, videos, or slideshows.

## Prerequisites
- Admin access
- Background media files (images or video)

## Procedure
1. Navigate to Admin > Backgrounds
2. Choose mode: Image, Video, or Slideshow
3. Upload media via drag-and-drop pad
4. For slideshow: reorder items, set transition interval
5. Configure overlay color and opacity
6. Set sizing mode (cover, contain, auto)
7. Preview changes in live preview panel
8. Save settings

## Verification
- Site frontend displays configured background
- Slideshow transitions at set interval
- Overlay renders with correct color/opacity
