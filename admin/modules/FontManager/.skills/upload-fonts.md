# Skill: Upload Custom Fonts

## Overview
Add custom web fonts to the site for use in typography settings.

## Prerequisites
- Admin access
- Font files in WOFF, WOFF2, TTF, or OTF format

## Procedure
1. Navigate to Admin > Fonts
2. Click Upload
3. Select font file(s)
4. Font is uploaded and @font-face CSS is generated
5. Use font family name in SiteSettings or custom CSS

## Verification
- Font appears in font list
- Font renders correctly when applied to text elements
