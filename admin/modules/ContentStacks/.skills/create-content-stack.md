# Skill: Create a Content Stack

## Overview
Build a reusable content block with mixed media, embeds, and multi-column layouts.

## Prerequisites
- Admin access

## Procedure
1. Navigate to Admin > Content Stacks
2. Click "New Stack"
3. Enter stack name
4. Add blocks: text, media, embed, or HTML
5. Configure column layout (1, 2, or 3 columns)
6. Drag to reorder blocks
7. Save stack
8. Copy shortcode `[[panel:content-stack-{N}.php]]` to embed in pages

## Verification
- Stack appears in stack list
- Shortcode renders content on target page
- Layout displays correctly on frontend
