# Skill: Sync Facebook Events

## Overview
Import events from a Facebook Page into the CMS event system.

## Prerequisites
- Admin access
- Facebook Page access token
- Facebook Page ID

## Procedure
1. Navigate to Admin > FB Events
2. Enter Facebook Page ID and access token
3. Click Sync to import events
4. Imported events appear in EventsManagerPro

## Verification
- Events from Facebook Page appear in CMS event list
- Event details (title, date, description) match Facebook source
