# FacebookEvents — Skills Reference

## Overview
Facebook Events integration module that syncs and displays events from Facebook Pages. Imports events from connected Facebook Pages into the CMS event system.

## Capabilities
- Sync events from Facebook Pages
- Display Facebook events on CMS pages
- Configure Facebook Page connection
- Event data import and display

## API Endpoints
- Module uses Facebook Graph API for event sync

## Data Storage
- Event data synced into EventsManagerPro data directory

## Dependencies
- Facebook Page access token configuration

## Common Tasks
1. **Connect Facebook Page**: Enter Page ID and access token in settings
2. **Sync events**: Trigger sync to import Facebook events
3. **Display events**: Synced events appear in EventsManagerPro
